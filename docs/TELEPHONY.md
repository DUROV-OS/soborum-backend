# Звонки МегаФона в Соборуме

Модуль хранит внешний архив звонков, связывает номер с карточкой клиента и карточкой продаж,
сохраняет аудио на сервере компании, распознаёт речь локальным faster-whisper и составляет
краткий разбор локальной моделью Ollama. Облачные AI API для звонков не используются.
Наличие исходников не подтверждает подключение ВАТС или развёртывание worker.

## Сценарий сотрудника

В карточке клиента и в карточке продаж есть блок «Звонки клиента». В разделе продаж
есть общий архив «Звонки компании». Для каждой записи показываются дата, направление,
сотрудник, длительность и стадия обработки. Запись загружается только по нажатию, через
авторизованный backend. Полный текст содержит временные отметки. Переход по отметке
работает после открытия аудио. Для монофонической записи роли собеседников не выдумываются.
Разбор содержит резюме, ключевые моменты и следующие действия с цитатами из транскрипта.
Эти предложения сами не меняют задачи, цены и договорённости в карточке.
Сотрудник может отметить разговор проверенным; автор и время проверки сохраняются.

Неизвестные номера и совпадения с несколькими карточками видны в фильтре
«Без привязки / спорные номера». Чтобы прикрепить запись, нужно открыть целевую карточку,
включить этот фильтр и нажать «Привязать к этой карточке». Ручное решение имеет приоритет
над автоматическим подбором; исправление связи журналируется через API.

## Контракт ВАТС

Официальная документация: https://api.megapbx.ru/#/docs/crmapi/v1/requests

`POST /api/telephony/megafon`, `application/x-www-form-urlencoded`, `crm_token` в теле.
Команды `history`, `event`, `contact` и `rating` принимаются без передачи содержимого модели.
Повторный `(provider, callid)` обновляет существующий звонок. Поздний `event` не затирает
итоговую историю, пустая ссылка не удаляет уже полученную запись. `contact` не меняет
маршрутизацию звонков. Доступ к прослушиванию/тексту — действующее право просмотра
раздела «Клиенты», ручные действия — право редактирования этого раздела.

Конфигурация: `MEGAFON_CRM_TOKEN` (минимум 32 символа), `MEGAFON_API_TOKEN`,
`MEGAFON_DOMAIN`, `MEGAFON_RECORDING_HOSTS` (точные проверенные имена серверов записи).
Внешние URL записей и ключи не отдаются в карточки. Для скачивания разрешён HTTPS,
запрещены частные IP, нестандартные порты, встроенные credentials и редиректы.
Лимит одного аудио — 200 MiB. Ошибки не содержат подписанных ссылок.

## Локальная обработка и загрузка истории

Сначала применить Alembic `upgrade head` после резервной копии и проверки на отдельной БД.
API остаётся закрыт с 503, пока входящий ключ не настроен.
Worker запускается отдельно, с `requirements-calls.txt` или `Dockerfile.calls`.
`docker-compose.calls.yml` — явный дополнительный профиль `calls`, без публичных портов.
Модель анализа следует скачать в `call-analysis` командой `ollama pull qwen3:1.7b`.
Распознавание использует модель `small`, CPU int8; качество нужно принять на реальных записях.
На маленьком VPS ограничить нагрузку и следить за памятью/очередью, не запускать несколько
worker без оценки ресурсов. Лизинг одной записи и восстановление после сбоя предусмотрены.

Для первоначального архива:

```sh
python -m app.telephony.archive --since 2026-05-28 --until 2026-10-30
```

Границы UTC, окончание исключительное. Импорт обходит дни, делит переполненные интервалы,
повторный запуск безопасен. После первоначальной загрузки worker раз в десять минут сверяет
последние двое суток, чтобы получать запоздавшие записи. Отсутствие аудио у оператора
показывается как ожидание; текст не создаётся из несуществующей записи.

Файлы — приватный `STORAGE_DIR/calls`, модели — отдельный cache. Резервная копия должна
включать таблицы `phone_calls`, `phone_call_audit` и этот каталог аудио. Исходная запись,
распознанный текст и ИИ-выводы не заменяют друг друга. При недоступности модели текст
сохраняется, обработку можно повторить. Для помощи во время разговора нужен отдельный
доступ к живому звуку: этот модуль обрабатывает завершённые телефонные звонки.

## Проверка перед включением

Тесты `tests/test_telephony.py`: ключ/выключенный callback, повторы, поздние события,
совпадения номера, ручное связывание, права просмотра и проверки, недоступное аудио,
опасные URL, сохранение текста при сбое ИИ, восстановление лизинга и повторная загрузка
архива. Проверить миграцию на PostgreSQL и реальный разговор от записи до карточки.
После подключения сверить количество звонков и записей с ВАТС за одинаковый период.
