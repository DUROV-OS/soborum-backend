# Календарь: сравнение с Битрикс24 и реализация

Дата проверки: 17 ноября 2026. Источники — официальная справка, не предположение о возможностях конкретного тарифа.

## Что уже работает в Durov OS

- Календарь доступен каждой действующей учётной записи, включая менеджеров без доступа к другим модулям. Ссылка всегда видна внутри «Совместной работы», без дублирования.
- День, неделя, рабочая неделя, месяц, расписание. Минутная сетка, пересечения рядом, перенос одиночной встречи.
- Создание, изменение, отмена, ежедневные/еженедельные/ежемесячные серии, приглашение сотрудников и ответы.
- Отдельные экраны личного календаря, занятости команды, планировщика и настроек. Часовые пояса, категории, рабочий график, подбор свободного времени.
- Организатор редактирует, приглашённые видят подробности, посторонние — только занятость. Версии и история изменений на сервере.

## Дополнение этого выпуска

| Возможность | Реализация и границы |
|---|---|
| Отдельные приглашения | Предстоящие встречи без ответа, одна ближайшая встреча на серию, независимо от открытого месяца. Просроченные и отменённые исключены. |
| События на весь день | Полночь в часовом поясе события, включительный последний день в форме, исключительное окончание в хранилище. Отдельная строка над часовой сеткой. Повторения сохраняют границы дня при DST. |
| Напоминания | В начале, за 5/15/30/60 минут или день. Сервер выбирает только разрешённые пользователю встречи. Опрос раз в 30 секунд в открытом приложении; отмена и отказ участника исключают напоминание. «Понятно» скрывает его до перезагрузки. Это не фоновый push и не email. |
| Экспорт | ICS и CSV для Excel: снимок выбранного периода либо списка приглашений с фильтрами. Отдельные вхождения серии, без будущих скрытых повторений. UTF-8, UTC для встреч, DATE для событий на весь день, защита формул CSV. Это не подписка/синхронизация. |
| Фильтр участника | По организатору и приглашённым, в дополнение к категории и поиску темы/описания. |
| Рабочая неделя | Отображает дни из личных настроек, включая нестандартный график. Переход между неделями — семь календарных дней. |

Новой миграции не требуется: новые поля хранятся в существующем JSON события. Для старых событий напоминание выключено, all_day=false. Реальные встречи и приглашения не создаются во время проверки.

## Остающиеся отличия и порядок работы

1. **Переговорные и оборудование.** Справочник помещений, вместимость, доступность, транзакционная блокировка пересекающихся броней, включая повторения. Нужны названия реальных помещений/ресурсов и кто ими управляет. Внешнее API не требуется.
2. **Календари компании, проектов, делегирование.** Отдельные права просмотра занятости/подробностей/создания/редактирования. Нельзя превращать общий доступ к разделу в раскрытие личных встреч. API внешней площадки не требуется; правила общего доступа должны быть явными.
3. **Одна встреча серии.** Исключения с исходной датой, перенос/отмена одного вхождения, защита от конфликтов и корректный экспорт. Сейчас редактируется целая серия; интерфейс это сообщает.
4. **Доставка при закрытом приложении.** Фоновая очередь, повторные попытки, дедупликация, журнал доставок. Для писем нужен подтверждённый корпоративный отправитель; для push — настроенные ключи, подписка устройства и разрешение пользователя. Не обозначать письмо доставленным по одному сохранению встречи.
5. **Синхронизация Google/Яндекс/Outlook.** Подключения OAuth/CalDAV, хранение токенов, отмена доступа, двустороннее сопоставление событий и разрешение конфликтов. Нужны аккаунты и разрешения провайдеров. ICS-файл не заменяет этот механизм.
6. **Слоты для внешних клиентов.** Отзываемые ссылки, срок жизни, ограничение запросов, проверка контакта, защита от двойной записи. Публикуется только доступное время. Ссылки не включены автоматически.
7. **Связи с CRM/задачами и вложения.** Проверка прав на каждый связанный объект/файл, синхронизация срока задачи без второго независимого источника истины. Совместный редактор документов — отдельная интеграция.

Это рабочее дополнение календаря, а не заявление о полном функциональном равенстве Битрикс24.
