# Диск: первый рабочий выпуск

Личные файлы доступны только владельцу, включая случай просмотра администратором. Общие файлы читают все действующие сотрудники; изменяет автор либо администратор. Область доступа после создания не меняется. Папки имеют один уровень, файлы перемещаются между папками внутри своей области доступа. Добавление файла в общую папку явно означает доступ всей команде.

Доступен вход в `/drive` из «Совместной работы». PDF, DOC/DOCX, XLS/XLSX, JPG/JPEG, PNG и ZIP — до 50 МиБ на файл, до 10 выбранных файлов за одну операцию интерфейса. Проверяются размер, расширение и сигнатура. Файлы скачиваются как вложения, не исполняются и не публикуются по анонимным ссылкам.

`drive_files` хранит карточку и её версию; `drive_revisions` — неизменяемые версии содержимого и SHA-256; `drive_folders` — личные/общие папки; `drive_changes` — автора, действие, основание запроса и цепочку контрольных сумм. Новая версия не перезаписывает прежние байты. Скачивание проверяет размер и SHA-256. Изменение требует актуальную версию карточки; повтор запросов определяется идентификатором и содержимым запроса. Корзина обратима, физического удаления через API нет.

Цепочка хешей позволяет обнаружить изменение сохранённой истории, но не является независимым блокчейном: внешнего закрепления контрольных сумм в этом выпуске нет. Регулярные резервные копии базы и каталога `STORAGE_DIR/drive` нужны совместно.

API:

| Метод и путь | Назначение |
|---|---|
| GET/POST `/api/drive/folders` | Папки области / создание |
| GET `/api/drive/files` | Поиск, папка, корзина, страницы |
| POST `/api/drive/files` | Загрузка или новая версия, multipart |
| PATCH `/api/drive/files/{id}/name` | Переименование с сохранением расширения |
| PATCH `/api/drive/files/{id}/folder` | Перемещение внутри области |
| POST `/api/drive/files/{id}/trash` | Обратимое удаление |
| POST `/api/drive/files/{id}/restore` | Восстановление |
| GET `/api/drive/files/{id}/history` | Версии и проверяемая история |
| GET `/api/drive/files/{id}/download` | Текущий файл или `revision_id` |

Каждый маршрут требует действующую учётную запись. Скрытые файлы возвращают 404, запрет изменения общего файла — 403, конфликт версии — 409. Метаданные и содержимое не кэшируются. Миграция `drive18112601` следует за `meet1811202601`; при параллельных изменениях схемы требуется согласовать общую голову миграций до выпуска.

Проверки: `pytest -q tests/test_drive.py`; фронтенд `npm run build`, `npm run test:drive` с preview на 127.0.0.1:5184. Тесты используют синтетические данные; проверяют приватность, права администратора, версии, конфликты, повтор запроса, восстановление, контрольные суммы, историю, очистку неуспешной загрузки, мобильный экран и доступ менеджера.

Дальнейшие отдельные этапы: вложенные папки и их управление, точечное предоставление доступа, редактор документов и согласование. Этот выпуск не заявляет их готовыми.
